## О принципе работы
Не бойтесь программа ничего не далает с вашим компьютером, кроме засорения памяти :)

### Способ окрашивания текста
Полная реализация находится в `source/pkg/color`
Используется окрашивание с помощью ANSI-кодов (`\033[...m`)
```go
"[\033[37m  Load resurs  \033[0m] " // пример окрашивания в цвет 37 - белый
```

### Поддержка пользовательских статусов
В данный момент, можно использовать свой список описаний статусов, программа ищет их в файле `data.txt` в дириктроии исполняемого файла. 

Формат файла `data.txt`:
``` data.txt
<Пользовательский статус 0>
<Пользовательский статус 1>
...
```
